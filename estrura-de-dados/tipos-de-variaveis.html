Tipos de Variáveis

As variáveis armazenam dados que podem ser definidos, atualizados e recuperados sempre que necessário. Os valores atribuídos a uma variável têm um tipo.

Em JavaScript, os tipos disponíveis são:

  • number (número);
  • string (alfanumérico);
  • boolean (booleano);
  • function (função);
  • object (objeto);
  • undefined (indefinido);
  • null (nulo);
  • arrays;
  • datas;
  • expressões regulares.
    •

    Embora a linguagem JavaScript tenha diferentes tipos de variáveis disponíveis, ela não é fortemente tipada. Isso se dá pelo motivo de que não é necessário declarar o tipo de variável, basta usar a palavra reservada var.
